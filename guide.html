메인 페이지
건물 전체 현황을 한눈에 확인하는 대시보드입니다.
미납·공실·만료 임박 세대를 빠르게 파악할 수 있어요.
🔢
상단 통계 카드
전체 현황을 숫자로 확인
1
전체
건물 내 전체 세대 수입니다. (2층~4층, 총 18세대)
2
임대중
현재 임차인이 있는 세대 수입니다. 탭하면 임대중 세대만 필터해서 봅니다.
3
공실
비어있는 세대 수입니다. 탭하면 공실 세대만 필터해서 봅니다.
4
미납
이번 달 월세를 아직 납부하지 않은 세대 수입니다. 탭하면 해당 세대만 봅니다.
🔴
이달 미납 현황
이번 달 월세 미납 세대 목록
1
목록 확인
이번 달 기준으로 납부 기록이 '미납'으로 등록된 세대만 표시됩니다.
2
세대 탭하기
목록에서 세대를 탭하면 해당 세대의 상세 입력 화면으로 바로 이동합니다.
💡 납부 기록은 어디서 입력하나요?
세대 페이지에서 세대를 탭한 뒤, 하단 '월세 납부 이력' 셀을 탭하면 완납/미납을 기록할 수 있어요.
⚠️
계약 만료 임박
30일 이내 계약 종료 예정 세대
1
임박 기준
계약 종료일까지 남은 날이 30일 이하인 세대가 자동으로 표시됩니다.
2
색상 구분
7일 이내는 빨간색, 8~30일은 주황색으로 표시되어 긴급도를 구분합니다.
📝
특이사항 메모
자유롭게 메모 작성
1
메모 작성
입력창에 내용을 쓰고 '추가' 버튼을 누르면 저장됩니다. 수리 요청, 공지사항 등을 기록하세요.
2
수정/삭제
각 메모의 ✏️ 버튼으로 내용을 수정하고, ✕ 버튼으로 삭제합니다.

세대 페이지
각 호실의 임차인 정보, 계약 내용, 월세 납부 이력을 관리하는 핵심 페이지입니다.
🏢
세대 목록 화면
층별 필터와 카드 현황
1
층별 필터
상단의 전체 / 2층 / 3층 / 4층 버튼으로 원하는 층만 볼 수 있습니다.
2
세대 카드
각 카드에 호수, 상태(임대중/공실), 임차인 이름, 월세, 납부 상태, 계약 D-day가 표시됩니다.
3
세대 탭하기
카드를 탭하면 해당 세대의 상세 입력 화면이 아래에서 열립니다.
상태 배지 설명
임대중 공실 ✅ 완납 ❌ 미납 D-3 D-15 D-60
✏️
세대 정보 입력하기
세대 탭 → 상세 입력 화면
1
임대 상태 선택
'임대중' 또는 '공실' 중 현재 상태를 선택합니다.
2
임차인 정보 입력
임차인 이름과 연락처를 입력합니다. 2인 공동 거주 시 임차인 ②에도 추가 입력 가능합니다.
3
계약 정보 입력
보증금, 월세(만원 단위), 계약 시작일과 종료일을 입력합니다.
4
특이사항 메모
수리 요청, 계약 관련 특이사항 등 세대별 메모를 자유롭게 입력합니다.
5
저장하기
하단 '💾 저장하기' 버튼을 누르면 모든 입력 내용이 저장됩니다.
⚠️ 주의
사진 업로드 중에는 저장 버튼을 누르지 마세요. 업로드가 완전히 끝난 후 저장해야 사진이 정상 저장됩니다.
📅
월세 납부 이력 관리
최근 12개월 납부 현황
1
이력 확인
세대 상세 화면 하단에서 최근 12개월의 납부 현황을 월별 셀로 확인합니다.
2
셀 탭하여 변경
각 월 셀을 탭할 때마다 상태가 변경됩니다.
기록없음 → ✅ 완납 → ❌ 미납 → 🗑 삭제 순서로 순환합니다.
3
자동 반영
변경한 내용은 바로 저장되며, 메인 페이지의 미납 현황에도 즉시 반영됩니다.
💡 납부 기록 순서
처음 탭 → 완납 기록
한 번 더 탭 → 미납으로 변경
한 번 더 탭 → 기록 삭제
📷
계약서 사진 추가
파일 선택 또는 카메라 직접 촬영
1
📁 파일에서 추가
스마트폰 갤러리나 파일함에서 이미 저장된 사진을 선택해 업로드합니다. 여러 장 동시 선택도 가능합니다.
2
📸 카메라 촬영
버튼을 탭하면 바로 카메라가 열립니다. 계약서나 신분증을 그 자리에서 바로 찍어 업로드할 수 있습니다.
3
업로드 대기
파란 진행 바에 퍼센트가 표시됩니다. '완료!'가 표시될 때까지 기다린 후 저장하세요.
4
사진 확인 및 삭제
업로드된 사진을 탭하면 크게 볼 수 있고, 사진 위 ✕ 버튼으로 삭제할 수 있습니다.
⚠️ 사진은 10MB 이하
사진 한 장당 10MB 이하만 업로드 가능합니다. 고화질 사진은 스마트폰 카메라 설정에서 해상도를 낮추거나 압축 후 업로드하세요.

수입·지출 페이지
월세 수입, 수리비, 관리비 등 건물 관련 수입과 지출을 기록하고 월별로 정산합니다.
📈
상단 요약 카드
이달 수입 / 지출 / 순수익
1
수입 (초록색)
선택한 월에 기록된 수입 합계입니다. (월세, 관리비, 보증금수입 등)
2
지출 (빨간색)
선택한 월에 기록된 지출 합계입니다. (수리비, 세금, 인건비 등)
3
순수익 (파란색)
수입에서 지출을 뺀 금액입니다. 마이너스면 빨간색으로 표시됩니다.
➕
내역 추가하기
우하단 + 버튼 탭
1
+ 버튼 탭
화면 우하단의 둥근 + 버튼을 탭하면 내역 추가 창이 아래에서 올라옵니다.
2
수입/지출 선택
📈 수입 또는 📉 지출 중 해당하는 것을 선택합니다.
3
카테고리 선택
수입: 월세, 관리비, 보증금수입, 기타수입
지출: 수리비, 청소비, 보험료, 세금/공과금, 인건비, 관리비지출, 기타지출
4
금액·날짜·메모 입력
금액은 원 단위로 입력합니다. (예: 500000) 날짜는 자동으로 오늘 날짜가 입력되며 수정 가능합니다.
5
저장
'💾 저장' 버튼을 누르면 목록에 바로 추가됩니다.
💡 월세 수입 입력 예시
수입 선택 → 카테고리: 월세 → 금액: 350000 → 메모: "201호 5월 월세" → 저장
🗓️
월 선택 및 조회
원하는 월의 내역 확인
1
월 선택기
상단 월 입력 필드를 탭해서 원하는 연도와 월을 선택하면 해당 월의 내역만 표시됩니다.
2
페이지 이동
내역이 10건을 넘으면 하단에 ◀ ▶ 버튼이 생겨 페이지를 넘길 수 있습니다.
3
내역 삭제
각 내역의 ✕ 버튼을 탭하면 삭제 확인 후 삭제됩니다.
📥
데이터 내보내기
CSV / JSON 파일 다운로드
1
CSV 내보내기
엑셀이나 구글 스프레드시트에서 열 수 있는 형식입니다. 회계 정리에 유용합니다.
2
JSON 내보내기
데이터 백업용 형식입니다. 현재 조회 중인 월의 데이터만 내보내집니다.

관리 페이지
전화번호부, 계약서 사진, 건물 설정, 백업/복구를 한곳에서 관리합니다.
상단 탭(📞 전화번호부 · 📷 계약서 · 🏠 건물 정보)으로 전환합니다.
📞
전화번호부
임차인·업체·중개사 연락처 관리
1
연락처 검색
상단 검색창에 이름이나 전화번호 일부를 입력하면 실시간으로 필터됩니다.
2
연락처 추가
'+ 추가' 버튼을 탭해 이름, 카테고리, 전화번호, 메모를 입력하고 저장합니다.
3
전화 연결
연락처 카드의 초록색 📞 버튼을 탭하면 바로 전화가 연결됩니다.
4
수정/삭제
✏️ 버튼으로 정보를 수정하고, ✕ 버튼으로 연락처를 삭제합니다.
카테고리 색상
세입자 업체/수리 공인중개사 기타
💡 전화번호 2개 등록 가능
한 연락처에 전화번호를 2개까지 등록할 수 있어요. 세입자의 본인/비상 연락처를 함께 관리하기 좋습니다.
📷
계약서 사진 관리
전체 세대의 계약서 사진 모아보기
1
사진 목록 확인
임대중이거나 사진이 있는 세대의 계약서 사진이 호실별로 정리되어 표시됩니다.
2
크게 보기
사진을 탭하면 전체 화면으로 크게 볼 수 있습니다. ✕ 버튼으로 닫습니다.
3
사진 추가
각 호실 카드 하단 '📷 사진 추가' 버튼으로 해당 세대에 사진을 바로 업로드할 수 있습니다.
4
사진 삭제
각 사진 우상단의 ✕ 버튼을 탭하면 확인 후 삭제됩니다.
💡 사진은 세대 페이지에서도 추가 가능
세대(🏠) 탭에서 호실을 탭한 뒤 '📸 카메라 촬영' 또는 '📁 파일에서 추가' 버튼으로도 업로드할 수 있어요.
🏢
건물 정보 탭
다중 건물 관리 · 호실 구조 설정
1
임대 건물 목록
'+ 건물 추가' 버튼으로 새 건물을 등록합니다. 목록에서 탭하면 해당 건물로 전환되고, 나머지 페이지에도 즉시 반영됩니다. 건물 삭제 시 해당 건물의 모든 데이터가 삭제되므로 주의하세요.
2
호실 구조 설정
'🔒 구조 수정' 버튼을 탭해 잠금을 해제한 뒤 층·호실 수를 설정합니다. '⚡ 자동 생성'으로 시작 층·끝 층·층당 호실 수를 입력하면 한 번에 생성됩니다. 저장 시 기존 구조가 교체되므로 신중하게 사용하세요.
3
건물정보카드
건물 주소, 현관 비밀번호, 기타 메모를 등록합니다. '+ 추가' 버튼으로 항목을 추가하고, 각 항목은 개별 삭제 가능합니다.
⚠️ 호실 구조 변경 주의
구조를 변경하면 기존 호실 목록이 교체됩니다. 임차인 정보가 없는 세대는 사라지므로, 처음 설정 시에만 사용하는 것을 권장합니다.
💾
백업 / 복구
건물 정보 탭 하단에 위치
1
백업 내보내기
세대 정보와 수입·지출 내역을 CSV·JSON으로 내보내고, 계약서 사진은 ZIP으로 묶어 다운로드합니다.
2
데이터 복구
JSON 백업 파일을 불러와 세대·수지 데이터를 복원합니다. 복구 시 현재 데이터가 덮어쓰이므로 주의하세요.
💡 정기 백업 권장
데이터 손실에 대비해 월 1회 이상 백업을 내보내두는 것을 권장합니다.

로그인 · 데이터 안전
Google 계정 기반 보안 · 사용자 승인
1
Google 로그인 후 승인 필요
처음 로그인하면 관리자의 승인을 기다리는 '승인 대기' 상태가 됩니다. 관리자가 승인을 완료해야 앱을 정상적으로 사용할 수 있습니다.
2
데이터 격리
모든 데이터는 본인 Google 계정에 연결된 Firebase에 저장됩니다. 승인된 계정 외에는 데이터에 접근할 수 없습니다.
3
실시간 동기화
변경 사항은 인터넷이 연결된 모든 기기에서 실시간으로 동기화됩니다.
4
로그아웃
헤더 우측 프로필 아이콘을 탭하면 계정 정보와 로그아웃 버튼이 나타납니다.
